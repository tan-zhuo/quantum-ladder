## 符号约定

全书统一使用的记号，供跨章阅读时对照：

| 符号 | 含义 | 备注 |
| --- | --- | --- |
| $\Psi(x,t)$ / $\psi(x)$ | 含时波函数 / 定态（空间部分）波函数 | 大写含时、小写不含时 |
| $\ket{\psi}$，$\bra{\phi}$，$\braket{\phi}{\psi}$ | 态矢、对偶矢、内积 | Dirac 记号，见 [3.2](/ch/03-formalism/02-dirac-notation/) |
| $\hat A$，$\hat A^\dagger$ | 算符及其厄米共轭 | 戴帽子的都是算符 |
| $[\hat A,\hat B]$，$\{\hat A,\hat B\}$ | 对易子 $\hat A\hat B-\hat B\hat A$、反对易子 $\hat A\hat B+\hat B\hat A$ | 花括号偶尔也表示集合，看上下文 |
| $\sigma_A$ | 可观测量 $A$ 的标准差（不确定度） | $\sigma_A^2=\langle\hat A^2\rangle-\langle\hat A\rangle^2$ |
| $\sigma_x,\sigma_y,\sigma_z$ | Pauli 矩阵 | 与不确定度的 σ 无关，习惯如此 |
| $\hbar=h/2\pi$ | 约化 Planck 常数 | 公式里几乎只出现 $\hbar$ |
| $\ii$，$\ee$，$\dd$ | 虚数单位、自然常数、微分号 | 正体排版，区别于变量 $i,e,d$ |
| $\delta_{mn}$，$\delta(x)$ | Kronecker 符号、Dirac δ 函数 | 离散用下标版、连续用函数版，见 [A.2](/ch/appendix-a-math/02-fourier/) |
| $\hat\rho$ | 密度算符 | 与概率密度 $\rho(x)$ 靠帽子区分 |

<Callout type="check" title="抄公式前的量纲三查">
1. 指数必须无量纲：$\ee^{-\ii Et/\hbar}$、$\ee^{-r/a_0}$、$\ee^{-2\gamma}$。
   指数上的组合如果不是无量纲的，一定抄错了。
2. 一维波函数量纲是 $1/\sqrt{\text{长度}}$（因为 $\int\lvert\psi\rvert^2\dd x=1$）；
   三维是 $1/\sqrt{\text{体积}}$。归一化系数对不上量纲就是丢了根号。
3. $\hbar$ 的量纲是能量 × 时间 = 动量 × 长度：任何公式里 $\hbar$ 的幂次
   都可以用这条独立验证一遍。
</Callout>

## 常用对易子与算符恒等式

下面是分散在各章、但各章都会用到的代数恒等式。$\hat A,\hat B,\hat C$ 为任意算符。

| 恒等式 | 说明 |
| --- | --- |
| $[\hat A,\hat B\hat C]=[\hat A,\hat B]\hat C+\hat B[\hat A,\hat C]$ | 乘积展开（类莱布尼茨规则），用于拆开长对易子 |
| $[\hat x,f(\hat p)]=\ii\hbar\,f'(\hat p)$，$[\hat p,g(\hat x)]=-\ii\hbar\,g'(\hat x)$ | 由 $[\hat x,\hat p]=\ii\hbar$ 逐阶推出 |
| $[\hat a,\hat a^\dagger]=1$，$\hat N=\hat a^\dagger\hat a$ | 谐振子/二次量子化的代数起点 |
| $[\hat J_i,\hat J_j]=\ii\hbar\,\epsilon_{ijk}\hat J_k$，$[\hat J^2,\hat J_i]=0$ | 任何角动量（轨道、自旋、总）通用 |
| $\ee^{\hat A}\hat B\,\ee^{-\hat A}=\hat B+[\hat A,\hat B]+\dfrac{1}{2!}[\hat A,[\hat A,\hat B]]+\cdots$ | Hadamard 引理：算符「换到旋转参考系」的展开式 |
| $\ee^{\hat A}\ee^{\hat B}=\ee^{\hat A+\hat B+\frac12[\hat A,\hat B]}$（当 $[\hat A,\hat B]$ 与两者都对易） | BCH 公式的可用特例；相干态、平移算符都会用到（[C.2 分步法](/ch/appendix-c-numerics/02-split-operator/)中 $[\hat T,\hat V]$ 不满足此条件，误差分析要用一般的 BCH 展开） |
| $\operatorname{tr}(\hat A\hat B\hat C)=\operatorname{tr}(\hat B\hat C\hat A)$ | 迹的轮换不变性；密度矩阵计算的日常工具 |
| $(\hat A\hat B)^\dagger=\hat B^\dagger\hat A^\dagger$ | 取厄米共轭要反序 |

## 物理常数与单位换算

做题时建议用「eV 制」组合常数，避免 $10^{-34}$ 量级的数值相乘：

| 常数 | 数值 | 用法提示 |
| --- | --- | --- |
| $\hbar$ | $1.055\times10^{-34}\ \text{J·s}=6.582\times10^{-16}\ \text{eV·s}$ | 频率 ↔ 能量 |
| $\hbar c$ | $197.3\ \text{eV·nm}=197.3\ \text{MeV·fm}$ | 长度 ↔ 能量，最常用的组合 |
| $m_ec^2$ | $0.511\ \text{MeV}$ | 电子静能；动能公式里配 $\hbar c$ 用 |
| $m_pc^2$ | $938.3\ \text{MeV}$ | 质子静能 |
| $\alpha=\dfrac{e^2}{4\pi\varepsilon_0\hbar c}$ | $\approx\dfrac{1}{137.04}$ | 精细结构常数，电磁作用强度 |
| $a_0$ | $0.0529\ \text{nm}$ | Bohr 半径 $=\hbar c/(\alpha\, m_ec^2)$ |
| $E_{\text{Ry}}$ | $13.606\ \text{eV}$ | Rydberg 能量 $=\tfrac12\alpha^2m_ec^2$ |
| $\mu_B$ | $5.788\times10^{-5}\ \text{eV/T}$ | Bohr 磁子，Zeeman 分裂用 |
| $k_BT$（300 K） | $\approx0.0259\ \text{eV}$ | 「室温 ≈ 26 meV」判断热效应是否重要 |
| $hc$ | $1240\ \text{eV·nm}$ | 光子能量 ↔ 波长：$E=1240/\lambda(\text{nm})$ eV |
| $1\ \text{eV}$ | $1.602\times10^{-19}\ \text{J}$ | 与 SI 制互换时才需要，一般不必换算 |
| $1\ \text{Å}$ | $0.1\ \text{nm}=10^{-10}\ \text{m}$ | 原子尺度的自然标尺（$a_0\approx0.53$ Å） |

<Callout type="check" title="快速自检：三个数量级直觉">
1. 可见光光子 $\approx1240/500\approx2.5$ eV，所以原子的 eV 级能隙对应可见/紫外光谱。
2. 室温 $k_BT\approx26$ meV，远小于原子能隙（原子在室温下待在基态），
   但可与半导体浅能级、分子转动能级相比。
3. 电子限制在 1 nm 内的动能 $\sim(\hbar c)^2/(2m_ec^2L^2)\approx0.04$ eV·$(\pi^2\approx10)\approx0.4$ eV，
   因此纳米尺度上量子效应很显著。
</Callout>
