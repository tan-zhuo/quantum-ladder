上一节我们对着谐振子把有限差分法走通了一遍。但每次换一个势都重新摆弄网格、单位和检查项，太不成体统。这一节做两件事：把方法**打包**成一个随取随用的求解器；再用它啃一块解析方法啃不动的硬骨头——**双势阱**——并从数值结果里读出真实的物理：氨分子的微波激射器，以及化学键的雏形。

## 求解器本体

代码几乎就是上一节的翻版，唯一的新意是把「势」作为参数传进去——任何能对数组求值的函数都行：

```python
import numpy as np
from scipy.linalg import eigh_tridiagonal

def solve(V, L, N, k=6):
    """解 -psi''/2 + V(x) psi = E psi（无量纲单位 hbar = m = 1）。

    V : 势能函数，接受 numpy 数组
    L : 求解区间 [-L/2, L/2] 的宽度（两端视为无限高墙）
    N : 内部格点数
    k : 要求的最低能级个数
    返回：格点 x、能级 E[0..k-1]、波函数 psi[:, i]（已归一化）
    """
    x = np.linspace(-L/2, L/2, N + 2)[1:-1]
    h = x[1] - x[0]
    diag = 1.0 / h**2 + V(x)
    off  = -0.5 / h**2 * np.ones(N - 1)
    E, psi = eigh_tridiagonal(diag, off, select='i', select_range=(0, k - 1))
    return x, E, psi / np.sqrt(h)
```

先跑一遍已知答案，确认没抄错：

```python
x, E, psi = solve(lambda x: 0.5 * x**2, L=16, N=1000)
print(np.round(E, 4))    # [0.5  1.5  2.4999  3.4998  4.4997  5.4995]
```

谐振子能级 $n+\frac12$ 如期而至。

**量纲怎么办？**代码用的是 $\hbar=m=1$ 的无量纲单位——这不是偷懒，是数值计算的标准操作：避免让 $10^{-34}$ 量级的数在浮点运算里乱窜。换算规则一句话：选定长度单位 $L_0$，能量单位就自动是 $\varepsilon_0=\hbar^2/(mL_0^2)$。对电子取 $L_0=1$ nm：

$$
\varepsilon_0=\frac{(\hbar c)^2}{mc^2\,L_0^2}=\frac{197.3^2}{511000\times1^2}\approx0.0762\ \text{eV}
$$

把真实势按 $\varepsilon_0$ 缩成无量纲数喂进去，算出的 $E$ 再乘回 $\varepsilon_0$，就是 eV。

<Callout type="warning" title="数值结果不会自己喊错">
解析推导错了往往推不下去；数值程序错了**照样输出一堆数**，而且看起来煞有介事。三个最常见的静默错误：

1. **单位混搭**——势用 eV、长度用 nm、却按无量纲公式组矩阵，结果差出几个数量级还自洽得很；
2. **盒子夹伤波函数**——高激发态的尾巴碰到假墙，能级被悄悄抬高（对底部较平、尾巴拖得远的势尤其危险）；
3. **归一化丢了 $\sqrt h$**——波形完全正确，一算概率全错。

抵御手段不是「更小心」，而是**制度化的验收**，见下面的清单。
</Callout>

<Callout type="check" title="验收清单：每解一个新势都过一遍">
1. **收敛**：$N$ 翻倍、$L$ 加大各重算一次，引用的位数必须纹丝不动（上一节的两个旋钮）。
2. **数节点**：第 $n$ 个态必须恰有 $n$ 个节点。多一个少一个，多半是求解器把态排漏了或盒子太小。
3. **查宇称**：势对称时波函数必须偶奇交替（[4.1 节](/ch/04-1d-problems/01-symmetry-parity/)的定理在此变成免费的测试用例）。
4. **验正交**：`psi[:,i] @ psi[:,j] * h` 应为机器精度的零。
5. **对极限**：把势参数推到某个已知情形（阱很深→无限阱、底部展开→谐振子），结果必须靠拢过去。
</Callout>

## 验收实战：双势阱

现在上主菜。取

$$
V(x)=V_0\,(x^2-1)^2
$$

两个极小值在 $x=\pm1$，中间隔着高 $V_0$ 的驼峰。这是解析方法的坟场——没有封闭解——却是物理的富矿：氨分子里氮原子在氢平面两侧的翻转、化学键中共享的电子、超导量子比特的双阱回路，全是它的变奏。

对求解器来说它毫无特殊之处，一行换势：

```python
x, E, psi = solve(lambda x: 20.0 * (x**2 - 1)**2, L=8, N=2000)
print(np.round(E, 3))    # [6.036  6.056  16.23  17.111  23.379  27.933]
```

盯住这串数字，它在讲一个故事：

- $E_0=6.036$ 与 $E_1=6.056$ **挤成一对**，只差 $\Delta E=0.019$；而 $E_1$ 到 $E_2$ 隔着足足 $10.2$。能级不再等距铺开，而是**成对出现、对内几乎简并**。
- 检查波函数：$\psi_0$ 是偶函数——左右两阱上各一个鼓包，同号相连；$\psi_1$ 是奇函数——同样的两个鼓包，右边反号，中间穿零。清单第 3 条通过：势对称，偶奇交替。
- 谐振子极限也对得上（清单第 5 条）：单个阱底附近 $V''(\pm1)=8V_0=160$，等效频率 $\omega=\sqrt{160}\approx12.6$，零点能约 $\omega/2\approx6.3$——与 $E_0\approx6.0$ 相符，差的那点正是非谐修正。

为什么挤成一对？想象驼峰无限高：左阱和右阱是两个隔绝的世界，各有一个基态，能量完全相同——**严格二重简并**。驼峰有限时，两阱的波函数尾巴在峰下[隧穿](/ch/02-wavefunction/11-tunneling/)相遇，简并被打破，一个能级劈成两个。$\Delta E$ 就叫**隧穿劈裂**，它直接量度两阱间「串门」的难易。

数值可以当场验证这层解释：把驼峰从 $V_0=20$ 降到 $10$，劈裂从 $0.019$ 跳到 $0.125$——驼峰高度减半，劈裂涨了六倍多。这种不成比例的剧烈响应正是 2.11 节隧穿指数 $\ee^{-2\kappa a}$ 的指纹：劈裂对势垒参数**指数敏感**。

## 从一对能级到来回振荡

近简并的一对能级不只是能谱上的装饰——它藏着一台钟。

<Derivation title="推导：粒子在两阱间的来回振荡" level="基础" minutes={8} open={true}>

**第一步：造出「在左阱」的态。**$\psi_0$（偶）和 $\psi_1$（奇）在左阱同号、在右阱反号，于是叠加

$$
\psi_L=\frac{\psi_0+\psi_1}{\sqrt2},\qquad
\psi_R=\frac{\psi_0-\psi_1}{\sqrt2}
$$

$\psi_L$ 在右阱处两项相消、左阱处相长——它**局域在左阱**；$\psi_R$ 反之。（系数 $1/\sqrt2$ 保持归一化；两式正交。）注意：$\psi_L$ 是两个不同能量本征态的叠加，**不是定态**——好戏由此开场。

**第二步：让它演化。**初态取 $\Psi(0)=\psi_L$。按第 2 章的老规矩给每个本征成分挂上相位钟：

$$
\Psi(t)=\frac{1}{\sqrt2}\left[\psi_0\,\ee^{-\ii E_0t/\hbar}+\psi_1\,\ee^{-\ii E_1t/\hbar}\right]
$$

**第三步：问它还在不在左边。**投影回 $\psi_L$（利用 $\psi_0,\psi_1$ 正交归一）：

$$
\braket{\psi_L}{\Psi(t)}=\frac12\left[\ee^{-\ii E_0t/\hbar}+\ee^{-\ii E_1t/\hbar}\right]
=\ee^{-\ii(E_0+E_1)t/2\hbar}\cos\frac{\Delta E\,t}{2\hbar}
$$

第二步提出了公共相位，剩下实实在在的余弦。概率为

$$
\boxed{\ P_L(t)=\cos^2\frac{\Delta E\,t}{2\hbar}\ }\qquad
P_R(t)=\sin^2\frac{\Delta E\,t}{2\hbar}
$$

**读结果。**粒子以周期 $T_{\text{osc}}=2\pi\hbar/\Delta E$ 在两阱间**整体来回搬家**：$t=\pi\hbar/\Delta E$ 时它百分之百在右阱。驱动这台钟的唯一参数是隧穿劈裂 $\Delta E$——劈裂越小（垒越高），搬家越慢。驼峰无限高的极限下 $\Delta E\to0$，周期无穷长：粒子被永远困在一边，回到「两个隔绝世界」的图像，自洽。

</Derivation>

<Callout type="insight" title="氨分子：一台走了亿万年的分子钟">
氨分子 NH₃ 是金字塔形：氮原子可以在三个氢构成的平面**上方或下方**，两个构型镜像等价——这正是一个双势阱，「翻面」要穿过一个约 0.25 eV 的势垒。

实验测得其隧穿劈裂 $\Delta E\approx9.8\times10^{-5}$ eV，对应频率 $\Delta E/h\approx24$ GHz：氮原子每秒钟在平面两侧来回搬家约 240 亿次。1954 年，Townes 用这对能级做出了人类第一台**微波激射器**（maser，激光的前身）——让处于上能级的氨分子受激辐射出 24 GHz 微波。你正在读的这套量子力学，最早的相干光源就是从一个双势阱的劈裂里出来的。

同一套双阱语言再往前一步就是**化学键**：两个质子夹一个电子（H₂⁺ 分子离子），电子看到的正是双阱。偶组合 $\psi_0$ 在两核之间堆积电荷、能量更低——**成键轨道**；奇组合 $\psi_1$ 在中间穿零——**反键轨道**。共价键的本质，就是电子选择了双阱的偶宇称基态。
</Callout>

<DualView>
<div slot="left">

**双阱是量子二能级系统的孵化器。**只要温度和扰动远小于 $E_2-E_1$ 那道宽约 10 的鸿沟（是劈裂 $\Delta E$ 的五百多倍），系统就被冻结在最低的一对态里——世界有效地只剩两维。「左/右」（或「上/下」）就是一个天然的量子比特，隧穿劈裂决定它的翻转速度。

超导量子比特的磁通双阱、固态缺陷里的隧穿二能级系统，设计思路都从这里出发。

</div>
<div slot="right">

有效二能级哈密顿量（以 $\psi_L,\psi_R$ 为基）：

$$
H_{\text{eff}}=\begin{pmatrix}\varepsilon&-\Delta E/2\\-\Delta E/2&\varepsilon\end{pmatrix}
$$

对角元 $\varepsilon=(E_0+E_1)/2$ 是单阱能量，非对角元由隧穿劈裂给出。对角化回 $\psi_0,\psi_1$，本征值 $\varepsilon\mp\Delta E/2$——数值算出的那对能级。

## 把它变成你的工具

这个求解器从此是你的实验台。几个值得亲手跑的势（每个都记得过验收清单）：

- **不对称双阱** $V_0(x^2-1)^2+\lambda x$：加一点点倾斜 $\lambda$，看近简并的一对如何被拆散、波函数如何各自缩回一个阱——4.1 节「势不对称则宇称失效」的数值版。
- **斜底阱** $V=\alpha x$（$x>0$，左端为墙）：三角形阱，半导体异质结界面处电子的真实处境。
- **截断谐振子**：把 $x^2/2$ 在某高度削平，数一数还剩几个束缚态，对照 4.1 节的 $z_0$ 计数经验。

写论文级的代码还会再加两样：Numerov 方法把精度从 $O(h^2)$ 提到 $O(h^4)$，虚时间演化处理二维三维——但骨架不变：**离散化、对角化、验收**。

## 本章结束

盘点一下这一章添置的家当：**宇称**用一个对易子把束缚态整理成偶奇交替，还免费划掉一批积分；**相移**把散射浓缩成一个角度，共振与束缚态在 Levinson 定理里握手；**传递矩阵**把多层结构变成 $2\times2$ 乘法，交出了共振隧穿和能带；**有限差分**把「算符即矩阵」落成代码，任意一维势从此都是十行程序的事。一维世界，至此可以说尽在掌握。

但真实的原子不是一维的。氢原子里的电子活在三维库仑势中，而三维带来一个一维根本没有的角色：**转动**。粒子可以绕着核转，转动有快慢、有方向——角动量登场。好消息是你的工具全都用得上：中心势下的三维方程可以分离出一个**径向方程**，它恰恰活在半轴上，正是 4.2 节那个「墙加势」的舞台。坏消息（其实是最精彩的消息）是角向部分自成天地：三个角动量分量**两两不对易**，$[\hat L_x,\hat L_y]=\ii\hbar\hat L_z$——第 3 章的对易子代数将不再只是判断「能否同时测准」的工具，而是亲手把角动量的取值一格一格**造**出来。
