上一节我们用谐振子把有限差分法完整走了一遍。但每次换一个势都要重新设置网格、单位和检查项，很不方便。这一节做两件事：把方法整理成一个可以直接调用的求解器；再用它处理一个解析方法难以求解的问题，即双势阱，并从数值结果中读出实际的物理：氨分子的微波激射器，以及化学键的雏形。

## 求解器

代码与上一节基本相同，区别只是把势作为参数传入，任何能对数组求值的函数都可以：

```python
import numpy as np
from scipy.linalg import eigh_tridiagonal

def solve(V, L, N, k=6):
    """解 -psi''/2 + V(x) psi = E psi（无量纲单位 hbar = m = 1）。

    V : 势能函数，接受 numpy 数组
    L : 求解区间 [-L/2, L/2] 的宽度（两端视为无限高墙）
    N : 内部格点数
    k : 要求的最低能级个数
    返回：格点 x、能级 E[0..k-1]、波函数 psi[:, i]（已归一化）
    """
    x = np.linspace(-L/2, L/2, N + 2)[1:-1]
    h = x[1] - x[0]
    diag = 1.0 / h**2 + V(x)
    off  = -0.5 / h**2 * np.ones(N - 1)
    E, psi = eigh_tridiagonal(diag, off, select='i', select_range=(0, k - 1))
    return x, E, psi / np.sqrt(h)
```

先用一个已知答案的问题检验代码：

```python
x, E, psi = solve(lambda x: 0.5 * x**2, L=16, N=1000)
print(np.round(E, 4))    # [0.5  1.5  2.4999  3.4998  4.4997  5.4995]
```

得到的正是谐振子能级 $n+\frac12$。

关于量纲：代码用的是 $\hbar=m=1$ 的无量纲单位，这是数值计算的标准做法，可以避免 $10^{-34}$ 量级的数进入浮点运算。换算规则是：选定长度单位 $L_0$ 后，能量单位就确定为 $\varepsilon_0=\hbar^2/(mL_0^2)$。对电子取 $L_0=1$ nm：

$$
\varepsilon_0=\frac{(\hbar c)^2}{mc^2\,L_0^2}=\frac{197.3^2}{511000\times1^2}\approx0.0762\ \text{eV}
$$

把实际的势除以 $\varepsilon_0$ 化成无量纲数输入，算出的 $E$ 再乘以 $\varepsilon_0$，单位就是 eV。

<Callout type="warning" title="数值程序的静默错误">
解析推导出错时往往无法继续推下去；数值程序出错时仍会输出一串数，而且看起来很合理。最常见的三种静默错误是：

1. 单位混用：势用 eV、长度用 nm，却按无量纲公式组装矩阵，结果差了几个数量级，表面上仍然自洽；
2. 盒子截断波函数：高激发态的尾部碰到人为的墙，能级被抬高而不易察觉（对底部较平、尾部延伸较远的势尤其要注意）；
3. 归一化时漏掉 $\sqrt h$：波形完全正确，但算出的概率是错的。

防止这些错误要靠固定的检查流程，见下面的清单。
</Callout>

<Callout type="check" title="检查清单：每解一个新势都逐项检查">
1. 收敛：$N$ 翻倍、$L$ 加大各重算一次，引用的各位数字必须保持不变（上一节讨论的两个参数）。
2. 数节点：第 $n$ 个态必须恰有 $n$ 个节点。多一个或少一个，多半是求解器漏掉了某个态，或者盒子太小。
3. 查宇称：势对称时波函数必须偶奇交替（[4.1 节](/ch/04-1d-problems/01-symmetry-parity/)的定理在这里可以直接用作测试）。
4. 验正交：`psi[:,i] @ psi[:,j] * h` 应在机器精度内为零。
5. 对极限：把势参数推到某个已知情形（阱很深→无限阱、底部展开→谐振子），结果必须趋近已知解。
</Callout>

## 应用：双势阱

现在来看主要的例子。取

$$
V(x)=V_0\,(x^2-1)^2
$$

两个极小值在 $x=\pm1$，中间隔着高 $V_0$ 的驼峰。它没有封闭形式的解析解，但物理上很重要：氨分子中氮原子在氢平面两侧的翻转、化学键中共享的电子、超导量子比特的双阱回路，都是这个模型的不同形式。

对求解器来说它并不特殊，只需换一行势函数：

```python
x, E, psi = solve(lambda x: 20.0 * (x**2 - 1)**2, L=8, N=2000)
print(np.round(E, 3))    # [6.036  6.056  16.23  17.111  23.379  27.933]
```

这串数字包含以下信息：

- $E_0=6.036$ 与 $E_1=6.056$ 靠得很近，只差 $\Delta E=0.019$；而 $E_1$ 到 $E_2$ 相隔 $10.2$。能级不再等距排列，而是成对出现，每对内部几乎简并。
- 检查波函数：$\psi_0$ 是偶函数，左右两阱上各有一个峰，符号相同；$\psi_1$ 是奇函数，同样的两个峰，右边反号，中间穿过零点。清单第 3 条通过：势对称，偶奇交替。
- 谐振子极限也符合（清单第 5 条）：单个阱底附近 $V''(\pm1)=8V_0=160$，等效频率 $\omega=\sqrt{160}\approx12.6$，零点能约 $\omega/2\approx6.3$，与 $E_0\approx6.0$ 相符，差别来自非谐修正。

能级为什么成对？设想驼峰无限高，左阱和右阱彼此隔绝，各有一个基态，能量完全相同，即严格的二重简并。驼峰高度有限时，两阱波函数的尾部通过[隧穿](/ch/02-wavefunction/11-tunneling/)在峰下交叠，简并被解除，一个能级分裂成两个。$\Delta E$ 称为**隧穿劈裂**，它直接反映粒子在两阱之间隧穿的难易程度。

这个解释可以用数值直接验证：把驼峰从 $V_0=20$ 降到 $10$，劈裂从 $0.019$ 增大到 $0.125$。驼峰高度减半，劈裂增大了六倍多。这种不成比例的变化与 2.11 节的隧穿指数 $\ee^{-2\kappa a}$ 同源：劈裂对势垒参数指数敏感。

## 从一对能级到来回振荡

近简并的一对能级还决定了一种周期运动。

<Derivation title="推导：粒子在两阱间的来回振荡" level="基础" minutes={8} open={true}>

第一步，构造局域在左阱的态。$\psi_0$（偶）和 $\psi_1$（奇）在左阱同号、在右阱反号，于是叠加

$$
\psi_L=\frac{\psi_0+\psi_1}{\sqrt2},\qquad
\psi_R=\frac{\psi_0-\psi_1}{\sqrt2}
$$

$\psi_L$ 在右阱处两项相消、在左阱处相长，因此局域在左阱；$\psi_R$ 则相反。（系数 $1/\sqrt2$ 保持归一化；两式正交。）注意 $\psi_L$ 是两个不同能量本征态的叠加，不是定态，所以它会随时间变化。

第二步，时间演化。初态取 $\Psi(0)=\psi_L$。按第 2 章的方法给每个本征成分乘上相位因子：

$$
\Psi(t)=\frac{1}{\sqrt2}\left[\psi_0\,\ee^{-\ii E_0t/\hbar}+\psi_1\,\ee^{-\ii E_1t/\hbar}\right]
$$

第三步，计算粒子留在左阱的概率。投影到 $\psi_L$ 上（利用 $\psi_0,\psi_1$ 正交归一）：

$$
\braket{\psi_L}{\Psi(t)}=\frac12\left[\ee^{-\ii E_0t/\hbar}+\ee^{-\ii E_1t/\hbar}\right]
=\ee^{-\ii(E_0+E_1)t/2\hbar}\cos\frac{\Delta E\,t}{2\hbar}
$$

第二个等号提出了公共相位，剩下一个实的余弦。概率为

$$
\boxed{\ P_L(t)=\cos^2\frac{\Delta E\,t}{2\hbar}\ }\qquad
P_R(t)=\sin^2\frac{\Delta E\,t}{2\hbar}
$$

结果表明，粒子以周期 $T_{\text{osc}}=2\pi\hbar/\Delta E$ 在两阱之间整体往返：$t=\pi\hbar/\Delta E$ 时它完全处在右阱。决定这个周期的唯一参数是隧穿劈裂 $\Delta E$，劈裂越小（垒越高），往返越慢。驼峰无限高的极限下 $\Delta E\to0$，周期趋于无穷：粒子始终停留在一边，回到两阱彼此隔绝的图像，结果自洽。

</Derivation>

<Callout type="insight" title="氨分子与微波激射器">
氨分子 NH₃ 是三角锥形：氮原子可以在三个氢构成的平面上方或下方，两个构型镜像等价。这就是一个双势阱，翻转要穿过一个约 0.25 eV 的势垒。

实验测得其隧穿劈裂 $\Delta E\approx9.8\times10^{-5}$ eV，对应频率 $\Delta E/h\approx24$ GHz：氮原子每秒在平面两侧往返约 240 亿次。1954 年，Townes 用这对能级做出了第一台**微波激射器**（maser，激光的前身），让处于上能级的氨分子通过受激辐射发出 24 GHz 微波。最早的相干辐射源就来自一个双势阱的能级劈裂。

同样的双阱模型再推进一步就是化学键：两个质子和一个电子（H₂⁺ 分子离子），电子感受到的就是双阱势。偶组合 $\psi_0$ 在两核之间积累电荷、能量更低，称为**成键轨道**；奇组合 $\psi_1$ 在中间穿过零点，称为**反键轨道**。共价键的成因在于电子处在双阱的偶宇称基态上。
</Callout>

<DualView>
<div slot="left">

双阱是构造量子二能级系统的常用模型。只要温度和扰动远小于 $E_2-E_1$ 这个约为 10 的能隙（是劈裂 $\Delta E$ 的五百多倍），系统就只能处在最低的一对态里，有效的态空间只有两维。「左/右」（或「上/下」）就构成一个量子比特，隧穿劈裂决定它的翻转速度。

超导量子比特的磁通双阱、固态缺陷中的隧穿二能级系统，设计思路都以此为基础。

</div>
<div slot="right">

有效二能级哈密顿量（以 $\psi_L,\psi_R$ 为基）：

$$
H_{\text{eff}}=\begin{pmatrix}\varepsilon&-\Delta E/2\\-\Delta E/2&\varepsilon\end{pmatrix}
$$

对角元 $\varepsilon=(E_0+E_1)/2$ 是单阱能量，非对角元由隧穿劈裂给出。对角化后回到 $\psi_0,\psi_1$，本征值 $\varepsilon\mp\Delta E/2$ 就是数值算出的那对能级。

到[第 5 章](/ch/05-angular-momentum/)会看到，这与自旋 1/2 的数学结构相同。

</div>
</DualView>

## 进一步的练习

这个求解器可以用来研究其他一维势。下面几个势值得自己计算（每个都要按检查清单检查）：

- 不对称双阱 $V_0(x^2-1)^2+\lambda x$：加一个小的倾斜 $\lambda$，观察近简并的一对能级如何分开、波函数如何各自集中到一个阱中，这是 4.1 节「势不对称则宇称不再确定」的数值验证。
- 斜底阱 $V=\alpha x$（$x>0$，左端为墙）：三角形阱，是半导体异质结界面处电子所处的势。
- 截断谐振子：把 $x^2/2$ 在某一高度截平，数一数还剩几个束缚态，与 4.1 节按 $z_0$ 计数的结果对照。

研究用的代码通常还会加入两种方法：Numerov 方法把精度从 $O(h^2)$ 提高到 $O(h^4)$，虚时间演化用于处理二维和三维问题。但基本步骤不变：离散化、对角化、检验。

## 本章结束

回顾这一章得到的工具：宇称通过一个对易子把束缚态整理成偶奇交替，还使一批积分不必计算；相移把散射归结为一个角度，共振与束缚态通过 Levinson 定理联系起来；传递矩阵把多层结构变成 $2\times2$ 矩阵乘法，给出了共振隧穿和能带；有限差分把「算符即矩阵」写成代码，任意一维势都可以用十行程序求解。一维问题到这里已经可以系统地处理。

但实际的原子不是一维的。氢原子中的电子处在三维库仑势中，而三维问题有一个一维问题中没有的要素：转动。粒子可以绕核转动，转动有快慢和方向，由角动量描述。已有的工具都还用得上：中心势下的三维方程可以分离出一个径向方程，它定义在半轴上，正是 4.2 节「墙加势」的情形。新的困难在于角向部分：三个角动量分量两两不对易，$[\hat L_x,\hat L_y]=\ii\hbar\hat L_z$。第 3 章的对易子代数将不只是用来判断两个量能否同时确定，还将用来逐级推出角动量的全部取值。
