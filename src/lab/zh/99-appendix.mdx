## 符号约定

| 记号 | 含义 |
| --- | --- |
| $\ket{\psi}$、$\bra{\psi}$ | 态矢量与其对偶 |
| $\braket{\phi}{\psi}$ | 内积（左边取复共轭） |
| $\hat A$ | 算符（戴帽） |
| $\vec r$ | Bloch 矢量 |
| $\rho$ | 密度矩阵 |
| $\psi_{n\ell m}$ | 氢原子波函数，下标依次为主、角、磁量子数 |
| $a_0$ | 玻尔半径 |

## 单位约定

为了让数值简洁，3D 场景一律采用**自然单位**：

- 一维问题：$\hbar = m = 1$。能量与长度都是无量纲的，只有比值有意义。
- 氢原子：$\hbar = m_e = e = 1$（原子单位）。长度单位是玻尔半径 $a_0 = 0.529$ Å，能量单位是 Hartree $= 27.211$ eV。
- 自旋：$\hbar/2$ 为单位，泡利矩阵的本征值取 $\pm1$。

场景里显示的数字都以这套单位表示。要换回国际单位，乘上相应的常数即可。

## 每个场景背后的数值方法

| 场景 | 方法 | 主要误差来源 |
| --- | --- | --- |
| Bloch 球 | 罗德里格斯有限转动 | 无（模长严格守恒） |
| 氢原子轨道 | 径向逆 CDF + 角向拒绝采样 | 蒙特卡洛统计涨落 $\sim 1/\sqrt N$ |
| 一维势阱 | 三点差分 + QL 求本征值 + 反迭代求本征矢 | 网格离散 $O(\dd x^2)$；有限窗口对弱束缚态的挤压 |
| 双缝 | 惠更斯子波直接求和（非远场近似） | 子波源数目有限（每缝 11 个） |
| 隧道效应 | split-operator，对称分裂 | 时间步（单步 $O(\dd t^3)$，累积 $O(\dd t^2)$）；边缘吸收层 |
| 路径积分 | 路径蒙特卡洛采样 | 采样数；离散时间步 |

数值方法的完整推导见[附录 C](/ch/appendix-c-numerics/01-finite-difference/)。
