## Notation conventions

The notation used uniformly throughout the book, for cross-chapter reading:

| Symbol | Meaning | Remarks |
| --- | --- | --- |
| $\Psi(x,t)$ / $\psi(x)$ | Time-dependent wavefunction / stationary (spatial) wavefunction | Uppercase carries time, lowercase does not |
| $\ket{\psi}$, $\bra{\phi}$, $\braket{\phi}{\psi}$ | State vector, dual vector, inner product | Dirac notation, see [3.2](/en/ch/03-formalism/02-dirac-notation/) |
| $\hat A$, $\hat A^\dagger$ | Operator and its Hermitian conjugate | Anything wearing a hat is an operator |
| $[\hat A,\hat B]$, $\{\hat A,\hat B\}$ | Commutator $\hat A\hat B-\hat B\hat A$, anticommutator $\hat A\hat B+\hat B\hat A$ | Braces occasionally also denote a set — read from context |
| $\sigma_A$ | Standard deviation (uncertainty) of observable $A$ | $\sigma_A^2=\langle\hat A^2\rangle-\langle\hat A\rangle^2$ |
| $\sigma_x,\sigma_y,\sigma_z$ | Pauli matrices | Unrelated to the uncertainty σ — convention, alas |
| $\hbar=h/2\pi$ | Reduced Planck constant | Formulas almost exclusively use $\hbar$ |
| $\ii$, $\ee$, $\dd$ | Imaginary unit, Euler's number, differential sign | Upright type, distinguishing them from variables $i,e,d$ |
| $\delta_{mn}$, $\delta(x)$ | Kronecker symbol, Dirac δ function | Subscript version for discrete, function version for continuous, see [A.2](/en/ch/appendix-a-math/02-fourier/) |
| $\hat\rho$ | Density operator | Distinguished from the probability density $\rho(x)$ by the hat |

<Callout type="check" title="Three dimensional checks before copying a formula">
1. **Exponents must be dimensionless**: $\ee^{-\ii Et/\hbar}$, $\ee^{-r/a_0}$, $\ee^{-2\gamma}$ — if what sits in an exponent cannot combine into a dimensionless quantity, you copied something wrong.
2. **A 1D wavefunction has dimensions of $1/\sqrt{\text{length}}$** (because $\int\lvert\psi\rvert^2\dd x=1$); in 3D it is $1/\sqrt{\text{volume}}$. A normalisation constant with the wrong dimensions means a lost square root.
3. **$\hbar$ has dimensions of energy × time = momentum × length**: the power of $\hbar$ in any formula can be independently verified with this line.
</Callout>

## Standard commutators and operator identities

The "algebraic ammunition depot" scattered across the chapters but used in every one. $\hat A,\hat B,\hat C$ are arbitrary operators.

| Identity | Remarks |
| --- | --- |
| $[\hat A,\hat B\hat C]=[\hat A,\hat B]\hat C+\hat B[\hat A,\hat C]$ | Product expansion (Leibniz-like rule); the whole business of unpacking long commutators |
| $[\hat x,f(\hat p)]=\ii\hbar\,f'(\hat p)$, $[\hat p,g(\hat x)]=-\ii\hbar\,g'(\hat x)$ | Follows order by order from $[\hat x,\hat p]=\ii\hbar$ |
| $[\hat a,\hat a^\dagger]=1$, $\hat N=\hat a^\dagger\hat a$ | The complete algebraic starting point of the oscillator / second quantisation |
| $[\hat J_i,\hat J_j]=\ii\hbar\,\epsilon_{ijk}\hat J_k$, $[\hat J^2,\hat J_i]=0$ | Universal for any angular momentum (orbital, spin, total) |
| $\ee^{\hat A}\hat B\,\ee^{-\hat A}=\hat B+[\hat A,\hat B]+\dfrac{1}{2!}[\hat A,[\hat A,\hat B]]+\cdots$ | Hadamard lemma: the expansion for "moving an operator to a rotating frame" |
| $\ee^{\hat A}\ee^{\hat B}=\ee^{\hat A+\hat B+\frac12[\hat A,\hat B]}$ (when $[\hat A,\hat B]$ commutes with both) | The usable special case of BCH; coherent states, displacement operators and the [C.2 split-operator method](/en/ch/appendix-c-numerics/02-split-operator/) all run on it |
| $\operatorname{tr}(\hat A\hat B\hat C)=\operatorname{tr}(\hat B\hat C\hat A)$ | Cyclic invariance of the trace; a daily tool of density-matrix calculations |
| $(\hat A\hat B)^\dagger=\hat B^\dagger\hat A^\dagger$ | Hermitian conjugation reverses the order |

<Callout type="check" title="Quick self-test: three order-of-magnitude intuitions">
1. A visible-light photon $\approx1240/500\approx2.5$ eV — so eV-scale atomic gaps map to visible/ultraviolet spectra.
2. Room temperature $k_BT\approx26$ meV — far below atomic gaps (atoms sit in their ground states at room temperature), but comparable to shallow semiconductor levels and molecular rotational levels.
3. An electron confined to 1 nm has kinetic energy $\sim(\hbar c)^2/(2m_ec^2L^2)\approx0.04$ eV·$(\pi^2\approx10)\approx0.4$ eV — the nanoscale is exactly where quantum effects take the stage.
</Callout>
