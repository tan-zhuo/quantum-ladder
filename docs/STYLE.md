# 文风规范

目标语气：一位讲课认真的物理老师写的讲义。陈述为主，结论直接写出来，不制造悬念，不喊口号。
参照对象是 Griffiths《Introduction to Quantum Mechanics》、曾谨言《量子力学教程》的叙述方式，
而不是科普公众号或产品落地页。

## 六条规则

### 1. 破折号少用

`——` 只在确实需要插入说明、且逗号或括号会产生歧义时使用，每节控制在三五处以内。
大多数情况换成逗号、冒号、括号，或者拆成两句。

- 改前：整体相位不可观测——$\ket{\psi}$ 与 $\ee^{\ii\alpha}\ket{\psi}$ 给出完全相同的所有测量结果——又去掉一个。
- 改后：整体相位不可观测（$\ket{\psi}$ 与 $\ee^{\ii\alpha}\ket{\psi}$ 给出相同的测量结果），又去掉一个。

### 2. 加粗只给新术语

加粗用于术语首次出现并给出定义的地方，例如「我们把 $\rho$ 叫做**概率密度**」。
不用加粗来表示强调；需要强调时靠句子结构，或者干脆删掉。

### 3. 不在段尾「点题」

删掉「这就是……」「这正是……」「这恰恰说明……」式的总结句。结论应该写在论证本身里。
「这就是受激辐射」这类**命名**句可以保留，但改成更平实的写法：「这个过程称为受激辐射」。

### 4. 少用「不是 X，而是 Y」

直接陈述 Y。只有当 X 是读者确实会有的误解、且这一节的任务就是纠正它时，才保留对比结构，
且一节里最多用一两次。

- 改前：所以修理方案不是绕开除法，而是先把「对的」零级态找出来。
- 改后：解决办法是先在简并子空间里找出合适的零级态。

### 5. 不自问自答，不写孤立短句段

- 「小到什么程度？小到……」→ 直接说「它小到可以……」
- 「那么——是什么在波动？」→「那么波动的究竟是什么量？」可以作为提出问题的句子，但不加破折号、不加粗。
- 「先看，再算。」「麻烦从这里开始。」这种单独成段的短句，并入前后段，或删掉。

### 6. 去掉空洞的加强词和营销腔

「真正」「恰恰」「彻底」「讲透」「绝不」「一句话」「主讲人」这类词，删掉后意思不变的就删。
Callout 标题用内容本身命名（「Born 规则」「要点」），不用「一句话版本」。

## 其他

- 人称：可以用「我们」指代作者与读者一起推导，用「你」指代操作场景的读者，但不要在一段里来回换。
- 口语词（「躺平」「天花板」「硬算」「执照」）在正文中替换为书面表达；标题里偶尔一处可以接受。
- 改文风时不改物理内容、公式、组件参数、frontmatter 里的 id 和 `related` 目标。
- 界面文案以中文原文为 msgid，改了中文就要同步改 `src/i18n/dict*.ts` 的键，并跑 `npm run i18n:check`。
